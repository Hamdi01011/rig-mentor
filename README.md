# Rig Mentor

Rig Mentor turns a character mesh into a working rig in a few clicks. Click the head, a wrist, the hips and an ankle: Rig Mentor finds every other joint, puts each one in the middle of its limb, and builds a regular armature or a full Rigify rig on them. It can then give any armature Rigify's face.

- Quick tutorial: https://www.youtube.com/watch?v=TiwWUT7PCKY
- Requires Blender 5.0 or later

## Report a problem or suggest an idea

1. Open the **Issues** tab at the top of this page.
2. Search the open issues first, in case someone has already reported the same thing.
3. Press **New issue** and choose **Bug report** or **Feature request**.

For a bug, a screenshot or a small .blend file that shows the problem helps the most.
